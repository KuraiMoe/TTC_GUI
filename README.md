# TTC 幻卡助手

《最终幻想 XIV》九宫幻卡（Triple Triad）桌面辅助工具：摆盘、拖拽落子、一键求解，给出推荐卡牌与落点，并支持选拔分析与卡组管理。

---

## 功能

### 对局求解

- **拖拽落子**：手牌可直接拖到棋盘落子（整张卡牌浮层跟随鼠标，带投影与缩放动画），随对局进程摆放局面；也支持棋盘内移动、收回手牌、手牌间互换。
- **选卡器**：点击任意卡位弹出选卡对话框，支持按 **名称 / 编号 / 拼音首字母 / 全拼** 搜索（如输 `ddn` 命中「渡渡鸟」、`duduniao` 同样命中），并可按星级筛选。
- **未知牌**：对手手牌可标记为「未知牌」。残局（棋盘已占 ≥ 5 格且未知牌 ≤ 2 张）自动启用信息集求解，从全卡库枚举合法候选构造多场景搜索；中局则采样多个可能世界分别求解后汇总推荐。
- **规则适配**：同数 / 加算 / 逆转 / 王牌杀手 / 同类强化 / 同类弱化 / 秩序 / 混乱，支持组合；同类强化弱化的类型修正自动计算。
- **搜索统计**：逐层加深的进度表（深度 / 最佳着法 / 评分 / 本层与累计节点 / 置换表命中 / 剪枝 / 耗时），实时刷新；结果区显示推荐着法（棋盘与手牌金框高亮）、估值与性能数据。
- **搜索参数**：时间上限、最大深度、未知牌采样数、激进模式，均可调。

### 选拔分析

- 三段备选（备选 1/2 各 3 组双卡、备选 3 为 3 组单卡）展开为 27 种完整卡组。
- 启发式评分（基础强度 / 规则适配 / 协同 / 稳定性 / 风险）+ 贪心对战深算验证（约 2/3 随机合法对手 + 1/3 高威胁对手采样对局）。
- 按总分排名输出推荐组合，附组件分、推荐理由、风险提示与分析日志；深算预算可调（5–20 秒）。

### 我的卡组

- 独立卡组编辑器：点击卡位选卡、命名保存。
- 卡组列表支持 **载入到对局**（一键填入我方手牌并跳转对局页）/ **编辑** / **删除**。

## 构建与运行

环境要求：Windows 10+，[.NET 10 SDK](https://dotnet.microsoft.com/download)

```powershell
# 开发运行
dotnet run --project src/TTC.Gui

# 发布：单文件自包含主 exe（无需 .NET 运行时）
dotnet publish src/TTC.Gui/TTC.Gui.csproj -c Release -r win-x64 `
    --self-contained true -p:PublishSingleFile=true `
    -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=none `
    -o dist/TTC_GUI
```

产物结构：

```
dist/TTC_GUI/
├── TTC_GUI.exe          # 单文件主程序
└── Data/
    ├── 幻卡数据库.csv
    └── card_pinyin.json
```
